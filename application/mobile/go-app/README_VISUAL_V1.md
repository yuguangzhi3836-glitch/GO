# GO App Complete Visual Build V1

This React Native client is the page-complete visual implementation layer for the GO Consumer hotel flow. It replaces the engineering-first Sprint 2A/2B screens with a coherent GO visual system while retaining the backend API contracts.

Start screen sequence:
Splash -> Login -> Home -> Search -> Hotel List -> Hotel Detail -> Rooms -> Booking Review -> Payment -> Success -> Trips -> Order Detail -> Change / Cancel / Stay Credit -> Notifications -> Quick Review -> My GO.

The static clickable visual reference lives in the delivery root under `visual-prototype/GO_App_Complete_Visual_Build_V1.html`.
