# 全国注册与酒店信息库候选 · 2026-09-19

用户最终确认第三项为“建立酒店信息库”，不是健康检查。本轮目标：C 端注册、B 端注册和全国新酒店建库。父版本为 PR #226 的 `f7595f4904d4415459fd0a938adaa35e01353959`。仅候选代码；未合并、未部署、未执行现场范围切换。

## 可用流程

- C 端未登录页头及登录页可进入注册，直接入口 `/go-app/#register`。从服务器读取注册状态和条款版本，注册明确同意必填，重复邮箱返回冲突；禁止通过额外字段请求管理员或酒店权限。注册后回读当前用户。
- B 端在 `/supplier-console/` 登录页申请入驻，填写酒店名称与自由省市地址，无试点城市名单。成功回读账户及新酒店编号，进入 `#/one-click-build` 酒店信息库；可创建自己的房型。新酒店仍为 DECLARED / DRAFT，审核前不自动公开、售卖或取得图片授权。
- 两端账户与资料、同意审计同事务提交，失败完整回滚；注册页面防重复提交及迟到响应覆盖。
- 管理端酒店网页工厂新增“全国建库范围与状态”。预览绑定指纹，权限校验后激活 NATIONWIDE，并重新读取状态。全国模式允许新酒店和新建库任务；此前 archived hotel IDs、retired jobs/runs 继续隐藏，不能把全国开放当作恢复旧酒店授权。

B 端酒店私有建档和管理端全国建库范围是两个入口：前者不因酒店不在试点城市而拒绝；后者若现场仍为 AOLUGUYA_ONLY，需要安装候选后实际切换并回读，不能仅凭源码宣称已经开放。
