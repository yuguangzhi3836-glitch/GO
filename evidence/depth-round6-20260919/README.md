# 酒店、房型可信审核与原图发布 · 2026-09-19

## 实际交付

- 酒店提交不可变清单，服务端保存标准化清单及 SHA-256；供应商只能提交自己的酒店。
- 沿用 GO_ADMIN + admin:rules 权限：读取、按精确哈希批准、撤销和发布。批准不等于发布。
- 审核绑定有效酒店登记、正式酒店、完整房型清单、逐项房型对应、原文件与当前图片授权。审批后酒店或房型事实变化使旧绑定失效。
- 图片发布接入现有 canonical profile、来源快照及页面版本，保留既有字段来源；不新建第二套发布事实。
- 官网采集合同保留原门禁；酒店自供原图使用独立合同。核心事实存在来源冲突时拒绝发布。
- 发布失败完整回滚，防止来源快照缺失或过时覆盖已审核事实。相同清单重试不重复创建页面版本。
- 新图片地址须关联当前公开页面及有效审批；每次读取重新检查授权、映射和原文件。撤销、原图损坏、库存变化或下架后拒绝访问。旧通用图片接口拒绝直接上传图片绕过审核。

## 验收范围

自动化测试使用隔离 SQLite、实际服务、合成 JPEG 原文件及 FastAPI 路由。API 权限测试仅替换 current_principal 为合成身份，保留实际供应商、管理员及 admin:rules 检查；不能等同生产登录验收。

最终测试数量与源码摘要见 SOURCE_BINDING.json、regression.log 和 final-targeted.log。后者在最后两项事务修复完成后运行。独立探针与复核结论见 INDEPENDENT_REVIEW.md。

## 尚未验证

- **真实浏览器页面验收仍未完成。** 已有浏览器尝试访问本地预览返回 ERR_BLOCKED_BY_CLIENT，本轮未绕过此限制。页面 JSON 与图片字节测试不代表界面截图验收。
- 未启动完整应用、未执行 PostgreSQL 并发或压力测试。数据库行锁不能由 SQLite 测试证明并发正确性。
- 尚无管理员审核界面及真实酒店操作验收，本轮是服务端可信审核和发布链路。
- 每次公开读取会复验清单图片，尚需评估大型图库性能；未把性能或生产就绪标为通过。
- 未导入或发布真实酒店素材，未修改携程。此前 19 个来源房型与 17 个正式房型的差异、275 个来源图片标识均不能当作本轮已核验资产。

仅提交私库草稿 PR；不合并、不部署。下一步应在可访问的预览环境接入审核界面，再用酒店确认的真实清单、原图和授权完成逐页验收。
