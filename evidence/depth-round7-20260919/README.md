# 酒店审核界面及运行验证 · 2026-09-19

候选父版本：PR #225，`5a708b38de32a52f92384275ab1c30ccf79c53c1`。本轮仍为草稿候选，不代表已安装到香港或正式环境。

## 已接入的操作

管理员在酒店网页工厂进入“酒店资料审核与图片发布”，按酒店编号及审核状态查询、分页查看。详情展示酒店身份、地址、正式房型与物理属性、原图尺寸、图片权利人与授权依据、当前授权核验及字段冲突。

批准、发布和撤销分别操作并重新读取状态。批准接口必须同时匹配已展示的清单哈希和酒店／房型事实哈希；资料在确认期间变化时拒绝审批。批准不代表发布，发布状态必须来自服务端实际页面回读。图片按需读取原文件，复用原有登录、角色及会话校验。

供应商可上传已经整理的审核清单文件，预览当前酒店、完整房型对应及图片授权声明，明确确认后提交；之后分页查看本酒店审核历史及公开回读状态。旧图片申请明确标为“发布意向”，不能替代正式审核。

**清单仍需资料整理人员准备。** 本轮未把来源平台的房型名称或图片编号自动转成可信正式身份，也不生成授权证明。

## 验证层级

- `frontend-final.log`：Node 控制器、请求与渲染测试，覆盖旧响应、重复确认、跨酒店／跨会话、清单及事实变化、文本转义、分页与原图认证。不是浏览器截图验收。
- `backend-final.log/xml`：当前服务及接口回归，隔离 SQLite 和合成资料。
- `runtime-probes.log/xml`：真实密码处理、管理员 MFA、签名 JWT、数据库会话、权限及两个供应商隔离；未替换 principal。另含 20 张测试原图的读取放大测量。
- `INDEPENDENT_REVIEW.md`：独立复核与修复记录，计数与上述测试重叠，不累加为总覆盖。
- `BROWSER_STATUS.json`：浏览器被 URL 策略阻断，本轮真实页面／手机场景执行数为 0。未绕过限制。
- `RUNTIME_ASSESSMENT.md`：完整应用恢复尝试、敖麓谷雅材料逐项核对及 PostgreSQL 验证条件；后续补取与实测结果以其更新为准。

## 按用户顺序保留的缺口

1. 审核界面与接口已有候选实现；必须继续用真实页面验收证明可用。
2. 整套应用启动、浏览器登录、手机适配不能由局部路由测试替代。完整运行证据与受限浏览器分开记录。
3. 敖麓谷雅现有包为 19 条来源房型、275 个图片标识、0 个原图文件；正式 17 房型 ID 和逐项映射尚未核实。资料包还缺部分房型设施、设施细节等，不能报告完整度 100%。
4. 当前无 PostgreSQL 运行工具，双连接行锁竞争未验证。20 图测量中页面读取原图 40 次，取单图读取 61 次；应消除同一次请求内重复校验，再扩大图库及并发验证。现有延迟仅为本机合成小文件观测。

未操作实际酒店发布、未合并、未部署。成果随草稿 PR 保存。
