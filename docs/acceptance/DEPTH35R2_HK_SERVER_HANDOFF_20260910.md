指挥中心完成适配并验证运行包装后，应同时提供：固定候选与源码指纹、完整文件和依赖清单、安装包或镜像校验值、独立资源配置、启动与停止方案、健康检查、可核对的合成账户初始化方式及证据采集规范。不能只给一句“拉最新代码部署”。
