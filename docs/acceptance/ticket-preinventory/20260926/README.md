## 本批已复现并修复

- 机票与铁路改签结案入口、共享supplier-fact入口拒绝只读/无订单操作权限管理员，仍要求真实管理员身份。共享入口适用于全部品类，其权限收紧需一并回归。

- 无效航班日期不写报价；精确过期时刻拒绝预订；SQLite无时区值与PostgreSQL带时区值统一按UTC比较。
- 初始机票出票事实必须有完整、唯一、有效的乘机人×航段票号；确认后票号身份不可变。
- 机票/铁路迟到checkout回写锁定并重读当前订单，不覆盖已出票、退款或其他后续状态。
- 合同模拟机票PNR使用确定性16字符内引用，完整订单ID保留在external_operation_id，避免PostgreSQL VARCHAR(16)溢出。没有创建实际航空PNR。
