## 问题与范围

隔离环境中，真实GO_READ_ONLY登录会话调用不存在快照的批准接口，返回409 CONTENT_SNAPSHOT_NOT_FOUND而非权限门403。未产生审批业务写入。原接口仅验证GO_ADMIN身份，服务相信请求中的HOTEL_AUTHORIZED_OPERATOR字符串；现有普通酒店staff角色接口也不能证明酒店真实委托。

本批限定修复内容审批链：路由和服务持久权限复核、酒店范围的隔离专用授权、制单审核分离、快照及审批证据绑定、最新拒绝优先和授权失效后的读回。缺少可信来源时保持HOLD。

隔离专用授权仅用于显式开启的测试环境，不能成为真实酒店授权，也没有公开授予接口。真实酒店首次授权建立、supplier/property/Hosted物理房型可信映射仍未完成。既有publish/page尚未完整消费内容gate；本批不是酒店发布或入住容量闭环。
