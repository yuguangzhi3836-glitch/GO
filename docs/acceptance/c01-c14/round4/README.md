## 本批范围

## 明确保留的缺口

现有押金模拟流程没有独立可信执行回执可据以恢复 UNKNOWN。缺回执、损坏图、未绑定资金或未知状态继续阻断资金动作；管理员确认不是恢复证据。本批不声称完成正向 UNKNOWN 恢复。

旧账本完整 BUSINESS 账户与当前 RD 账户不能仅凭总借贷平衡视为已冲销；若未实现精确原账户反向，补偿必须明确 HOLD。

携程学习对应的酒店入住容量闭环先完成只读设计与影响评估。后续需要授权酒店、物理房型与库存池的可信绑定，明确成人、儿童、总人数及婴儿规则，覆盖报价、下单、付费改期、额度兑换与历史成交快照。本批不把设计记录算作酒店能力已实现。
