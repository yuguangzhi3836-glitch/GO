## 已实现的修复

- 普通酒店和 GO Direct 新转换额度的到期日，不得晚于原订单创建后 365 天；较短的已接受有效期继续保留。报价固定到期时刻，执行、重复请求不会重新计时。历史已发额度和已执行报价不自动改写。

- 网页转换确认展示实际到期时间和原始订单一年上限，移除“转换后还有 365 天”的误导。GO Direct 同步说明。
- 原生额度页面分别展示额度期限和报价期限，要求明确同意；提交绑定同一订单、报价 ID、报价哈希及幂等键。会话变化、错误币种、过期报价和重复点击拒绝；响应丢失时读取原订单，不自动重复取消。原生领域方法已与真实隔离 FastAPI API 对接验证。
