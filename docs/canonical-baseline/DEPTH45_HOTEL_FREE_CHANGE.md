# DEPTH45 酒店退改规则替换及父包升级

用户最新决定：酒店参照机票的退改操作方式；改期本身不收手续费，一年内可用，贵了补差价，便宜了不退差价。随后明确要求新规则直接覆盖旧规则并升级父包。本次沿 PR47 原分支落实，旧含手续费代码不作为当前开发规则。

## 当前规则

- 所有新酒店改期报价的改期手续费固定为 0；同价、降价不扣款，涨价只补本次正差价。供应商发布接口拒绝非零改期手续费，供应商页面移除收费输入。
- 一年按原订单创建日起 365 天固定计算（已向用户说明的实施口径）。到期后不能申请改期；新入住的酒店当地入住时刻不得超过固定期限；连续改期不重置期限。报价和执行都校验。
- 降价差额不退、不生成余额、不能抵扣后续涨价。后续取消退款扣除已放弃的低价差额，避免通过取消取回该差额。
- 退款按下单确认的取消规则报价、确认和原路处理。本次没有推定“退款也免手续费”，也没有将机票中的固定模拟金额搬进酒店计价。
- 普通酒店订单与 GO Direct 酒店改期均免手续费并受一年限制；网页及原生源码的规则展示同步。已成交历史账目保留原始金额，新报价执行新政策，未接受的旧报价须重新报价。
