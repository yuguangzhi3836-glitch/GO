# GO V13 — 宽圆弧字标

2026-09-09。以 V12 原件继续精修。

## 设计

- 英文字形独立绘制：A 改为带完整横画的圆拱结构；D／C 使用横向延展的圆弧；R 保持短斜腿。英文高度由 V12 的 350 降到 300，竖画由 56 降到 48。
- 中文保留“发现全世界 直接向官方预订”全部十二字的原始轮廓。字面高度由 244 降到 186，增大字间距，并区分两段短语。英文含加号与中文均为 3100 单位可见宽度。
- 红色加号由 200 缩至 160 单位，顶部与 T 齐平。GO 本体和中间红方块沿用 V12 原始矢量，不改变轮廓或颜色。
- 保留深蓝 #061B3A 和红色 #FF3B24。

## 文件与使用

- `GO_MASTER_V13.svg`：主展示版，右侧光学居中，组合高度约 665，GO 高度为 1000。右侧外框不与 GO 严格等高。
- `GO_MASTER_V13_EQUAL_HEIGHT.svg`：保留此前要求的严格等高布局，左右可见上下边界相同。字形不拉伸，仅移动两行位置。附同名 PNG。
- `GO_COMPACT_V13.svg`：窄页头简版，保留 GO 与 AI DIRECT+，附 200／160 像素样张。标语放在页面适合阅读的位置。
- `GO_SYMBOL_V13.svg`：GO 独立标志，附 48 像素样张。
- `GO_MASTER_V13_REVERSE.svg`：白字版，适配深蓝底。`GO_MASTER_V13_MONO.svg`：黑色单色版。
- `GO_MASTER_V13_TRANSPARENT.png`：透明底大图。常规预览 PNG 为白底。
- `GO_APPLICATIONS_V13.png`：静态应用检查图，不代表已经修改网站。

完整版建议展示宽度至少 480 像素。400 像素时中文较小；320 像素不宜作为需要阅读完整标语的场景。手机窄页头使用简版。

所有字形为固定矢量轮廓，不依赖外部字体或图片。已检查完整十二字、英文／中文两端对齐、加号顶部、GO 等大、画布留白；主版经 Inkscape 与 MuPDF 两种渲染器检查。
