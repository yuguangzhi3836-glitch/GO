# DEPTH30：原生端支付与退订候选

此候选修复六品类原生支付／取消入口的实际接入缺口。消费者使用资料库出行人建立待付款订单，核对当前金额后单独确认隔离模拟支付；取消时读取报价，提交后重新读取原订单。租车、接送取消页不再直接跳转“退款成功”。酒店下单补齐明确退改规则确认和规则指纹。

登录续期重发保留同一请求体和防重复编号；并发续期共享一次刷新。退出撤销会话并清理本机凭据，旧账号迟到响应不能恢复旧登录。请求超时后不自动重发交易。租车与接送的价格、押金和等候时间缺失时不再填入虚构默认值。
