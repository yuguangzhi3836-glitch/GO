# GO 品牌标志 V6

本版承接已保存的 V5，精修英文词间距，并补齐窄页头的专用资产。大师级品质是设计目标，不将主观评分写成验收事实。

父提交：`9113662a85a14ff9783fdd7708c02a3f4b682693`。原封存资产保留，本目录为独立交付。

## 本轮变化

- 完整版中 AI 与 DIRECT 的可见词间距从 200 调至 270 设计单位；相邻字母间距按原节奏收紧，总宽度保持不变。
- G/O 字形、中央红块、中文全部轮廓与字重、分隔线及安全边距均保持原样。
- 新增单行简版 `go-compact-lockup-v6.svg`，供较窄的页头使用。简版保留 GO 与 AI DIRECT+，完整标语仍在主版本中。
- 新增纯 GO 小标志 `go-mark-v6.svg`。所有标志均为轮廓矢量，不依赖终端字体。

## 使用规范

按实际分配给标志的宽度选择，不按整个屏幕宽度判断。

| 标志可用宽度 | 建议资产 | 内容 |
| --- | --- | --- |
| 至少 320 px | `go-main-lockup-master-v6.svg` | GO、AI DIRECT+、完整中文标语 |
| 160–319 px | `go-compact-lockup-v6.svg` | GO、AI DIRECT+ 单行组合 |
| 32–159 px | `go-mark-v6.svg` | GO 图形 |

以上下限依据本次 1 倍静态栅格样张确定，实际使用还须结合容器背景、显示密度和交互空间。小于 32 px 未作验证。

固定品牌颜色为深蓝 `#061B3A` 与红色 `#FF3B24`。本次验证使用白底；不可自行拉伸、裁切 viewBox 或压缩中文来适配容器。保持图像原始宽高比，使用原 SVG 内的安全边距。

`GO_MASTER_V6.png` 为完整版展示图；`GO_COMPACT_V6.png` 为简版展示图；`GO_APPLICATION_PROOF.png` 展示完整版、窄页头和小图标的实际比例。其余小尺寸 PNG 为 1 倍检查样张。主版本与简版另由 MuPDF 独立渲染，用于检查字体依赖与裁切问题。

`source_changes/frontend/consumer/app.js` 仅将上一版本的标志引用替换为 V6 文件名和缓存版本；未加入自动切换简版的页面逻辑。`go-main-lockup.svg` 与主版本字节一致，供既有兼容路径使用。

本包仅为设计资产及待集成源码，不代表已更新运行中的网页。检查范围为矢量几何、静态渲染和文件一致性，不包含真实手机、三端登录、香港环境或任何发布门禁。本次未部署、合并或改动生产环境。

`build_verify.py` 可在同级保留 V5 目录时重建本包的图形与几何记录；需要 Python fontTools、Pillow、PyMuPDF 和 Inkscape。`SHA256SUMS` 记录交付文件指纹（不包含清单自身）。
