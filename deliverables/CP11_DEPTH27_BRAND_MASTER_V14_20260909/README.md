# GO V14 — 字距与整体比例精修

2026-09-09。延续 V13 圆拱 A 与宽圆弧英文，收紧中文阅读节奏。

## 本轮调整

- 右侧英文（含加号）与中文由 3100 收至 2700 单位，缩短约 12.9%，两行可见左右边界仍一致。
- 中文字面高度维持 186 单位，不压扁、不缩窄字形；常规字间距由约 78.08 调至 43.53，收回约 44.2%。两段短语间另留 80 单位间隔，完整保留“发现全世界 直接向官方预订”。
- 英文高度由 300 调至 280，保留 V13 字形比例及圆弧结构；重新分配字偶间距。红色加号为 150 单位，顶部与 T 齐平。
- GO 与文字间隔由 330 调至 250 单位，整组可见总宽由 5480 缩至 5000，缩短约 8.8%。
- GO 图形与中央红块沿用原矢量，颜色为深蓝 #061B3A、红色 #FF3B24。

## 核验

已核对 GO 及十二个中文轮廓、英文原始路径、两行等宽、加号顶齐、完整“订”字、画布留白和两种渲染器的静态输出。全部字形为固定矢量轮廓，无外部字体、图片依赖。

`DESIGN_VERIFIED.json` 记录几何与样张，`SHA256SUMS` 记录校验值。`build.py` 使用 Python 3、fontTools、Pillow、PyMuPDF、Inkscape 生成文件；`package.py` 封包并逐项核对 ZIP 内容，固定 ZIP 元数据避免仅因打包时间改变封包哈希。

本轮为品牌资产，不修改网站或香港运行环境；静态图检查不等同于真实浏览器／移动端验收。
