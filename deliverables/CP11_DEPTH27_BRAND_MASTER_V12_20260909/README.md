# GO V12 — 定制低字面精修

2026-09-09。仅为品牌静态资产，不修改网页、登录流程或香港运行环境。

## 本轮设计

- 英文使用新绘制的填充轮廓，不依赖系统字体。350 单位字高，主要横画 54、竖画 56；保持低字面，不再使用 V11 的描边中心线。
- A 的横画收在字形内部；R 使用封闭圆弧字腔，缩短斜腿；D/C 采用同心圆弧构造；E/T 收尾为 16 单位、45°小切角，与 GO 横画斜切呼应。
- AI 与 DIRECT 词距独立设置，字偶间距逐对分配。英文含加号与中文两行可见宽度均为 3100 单位。红色加号顶部与 T 顶部一致，外框仍为 200 × 200。
- G/O 的 1000 单位外圈、670 单位内圈以及中央红块的原始几何保持不变。中文完整保留 V7 的 12 个轮廓，包含完整“订”字，不裁字、不使用网页字体。

## 两种布局，不覆盖旧决定

- `GO_MASTER_V12.svg`：建议预览版。右侧组合高度 815，置于 GO 内光学居中，英文从 y=105 到 455，中文底边 y=920。右侧外框与 GO 不严格等高；这一调整用于减轻右侧视觉重量。
- `GO_MASTER_V12_EQUAL_HEIGHT.svg`：保留此前锁定的“左右整体等高”版，左右外框均为 y=0…1000。仅移动两行位置，不拉伸任何字形，英文与中文仍等宽，加号与 T 仍顶齐。

## 使用

- 主版适合宽页头和清晰可读的品牌展示。400 px 整组静态样张已检查；320 px 的中文较小，不作为正文阅读大小使用。
- 窄页头使用 `GO_COMPACT_V12.svg`，仅保留 GO 与 AI DIRECT+；附 200/160 px 静态样张。标语需由邻近页面文本另行呈现，不把完整中文强行缩小。
- 小图标使用 `GO_SYMBOL_V12.svg`；附 48 px 样张。
- `GO_MASTER_V12_REVERSE.svg` 为深蓝底白字版，`GO_MASTER_V12_MONO.svg` 为单色版。SVG 不含外部字体、图片或脚本依赖。
- `GO_APPLICATIONS_V12.png` 为静态应用样张，不是移动端网页或真实设备验收结果。

## 核验与边界

`build.py` 可生成资产与几何核验记录，需要 Python 3、fontTools、Pillow、PyMuPDF 和 Inkscape。`DESIGN_VERIFIED.json` 记录可见边界、原始字形保留、对齐、留白及两种渲染器结果。

这些检查验证文件结构和静态输出，不证明商标可注册、网页无障碍达标、三端登录通过或香港发布通过；“大师级 10 分”是审美目标，不是可以由脚本认证的客观结果。
