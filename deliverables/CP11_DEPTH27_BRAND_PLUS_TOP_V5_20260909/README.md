# GO 红色加号与 T 顶部对齐 V5

基于 `db4864f158876baa0a0189ff48bd24bf2aa496c5` 精修版，按用户要求将红色“+”的实际笔画顶部与 T 顶部齐平。

加号保持大小和横向位置不变，仅下移；英文行整体向上归位，以保留左右整体等高。中文、G/O、中间红块、字形、横向字距、分隔线和安全留白保持原样，两行左右边界仍对齐。

`source_changes/` 保存两个 SVG 路径与消费者页头的一处版本资源引用变更。仅品牌候选归档，未改写原封存包，未部署或改变任何发布门禁。

`ALIGNMENT_VERIFIED.json` 为 Inkscape 独立测量的实际笔画边界记录；预览见 `GO_PLUS_TOP_V5.png`。
