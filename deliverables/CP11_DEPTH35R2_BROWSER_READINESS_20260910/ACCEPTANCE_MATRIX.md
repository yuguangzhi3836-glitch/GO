## 当前候选必须补验的身份与详情场景

1. 同一浏览器中消费者会话与控制台会话共存；退出其中一个，不应退出另一个。
2. 供应商账户尝试管理端、管理员账户尝试供应商端：显示角色错误，不得替换原有有效身份。只通过正常登录流程验证。
3. 控制台跨标签切换身份后，前一标签不能继续展示或操作前一身份的受保护信息。
4. 退出后重新登录、页面返回及正常会话续期：旧响应不能恢复旧账号。需要控制过期或网络条件的项目，只有正式支持的隔离验收能力可用时才执行，否则单列 NOT_RUN。禁止直接注入 Cookie、令牌或会话来制造通过。
5. 从真实界面进入 `/go-app/direct.html`，核对 V14 Direct 详情、房型与报价绑定、查看既有隔离订单及登录后的返回路径。页面存在或组件测试通过不能代替这条旅程。

原生 transport 的退出／续期测试与浏览器 Web 页面分别记录；本清单不证明 React Native 构建或设备验收通过。
