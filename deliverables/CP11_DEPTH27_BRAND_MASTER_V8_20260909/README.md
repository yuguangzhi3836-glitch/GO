# GO V8 标志与应用规范

V8 在用户确认的 V7 轻字重标志上精修，目标是更克制、均衡、清晰的品牌表达。

父版本：`c28ae4ff7514a0ec1417402920d85e46d65bb9fa`。

## 设计调整

- G 中间横笔由 150 减至 136 设计单位，斜切端头统一为 45°；圆环维持 V7 的 165 单位。
- G 与 O 的外圆直径均为 1000。红色连接块维持原位置、160 × 160 尺寸和原色。
- 取消分隔竖线，GO 与右侧文字的净距由 420 调为 360，强化整体关系。
- 中文可见高度由 280 调为 258，在两行等宽约束下重新分配字间留白，保留完整标语。
- 英文按字对调整间距；AI 与 DIRECT 之间保留明确词距。
- 正式双语版保留左右整体等高、上下两行可见边界等宽，以及加号与 T 顶部齐平。
- 字形与附加描边已固化为填充轮廓，使用时不依赖字体安装或软件描边解释。

## 已完成的检查

已测量左右高度、两行边界、加号顶部及末字安全范围，完整保留 12 个中文原始字形。已目视比较有无竖线的方案，选定无竖线版本。已检查白底、深蓝底、单色、400 px 主版、200/160 px 简版和 48/32 px 图标；320 px 主版作为限制样张保留。

主图、400 px 主版和 160 px 简版均有 Inkscape 与 MuPDF 两种渲染结果。检查记录见 `DESIGN_VERIFIED.json`，这些是静态图形证据；实际手机浏览器、印厂打样和应用集成尚未在本次设计任务内验证。审美上的满分不是可由几何校验自动证明的事实。

## 重建与校验

在本目录运行 `python3 build_verify.py` 可重建矢量与样张，需要 Python、fontTools、Pillow、PyMuPDF 和 Inkscape；原始 V7 已保存在 `inputs/`，且脚本核验其 SHA256。`SHA256SUMS` 列出交付文件哈希。

本目录为独立品牌设计交付。历史 V7、DEPTH27 封存源码和发布证据保持原样；本轮未改动业务应用或香港运行环境。
