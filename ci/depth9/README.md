## 本轮实际改动

1. 以当前 main 保留控制面，在 application 中合并已部署链与九个 C13 scoped 候选。保留多语言机场别名，并恢复组合回归发现遗漏的改签报价幂等处理。
2. 活跃机票命令每 3 秒续租，恢复线程采用相同机制。恢复领取按“请求行→资源行”加锁，逐条领取后立即执行，避免锁顺序反转和排队时租约过期。
3. PSP 结算凭据允许匹配同一支付根下的已确认部分扣款。原凭据重放保持不可变；对账仍要求 PSP、银行与借贷平衡的扣款账本一致。没有新增资金真相源。
4. 旧交易测试显式使用合成协议夹具，保留真实认证、Cookie、权限和数据库。正式协议仍为草稿，注册门槛保持关闭；测试夹具不代表法律批准或真实核验。
5. 浏览器旅程通过可见日历控件选择酒店和租车日期。统一三端入口缓存版本，新增本地 HTTP 并发基线，保留全部既有 CI 门槛。
